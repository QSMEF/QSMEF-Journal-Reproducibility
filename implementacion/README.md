# QSMEF — Computational Implementation and Reproducibility

This directory contains the computational implementation and regression-testing artifacts associated with **QSMEF** (*Quantum Software Engineering Module Evaluation Framework*). QSMEF evaluates the functional contribution of blocks in quantum circuits using coalition-based observable measurements and Shapley values, subject to declared technical, functional, and semantic applicability conditions.

For the research objective and the organization of the complete archive, see the [repository overview](../README.md).

## Computational approach

For a declared decomposition into functional blocks, QSMEF constructs coalitions by replacing omitted blocks with identity operations while preserving the specified circuit order. Each coalition is evaluated against the same declared observable and baseline. Shapley values summarize the resulting marginal contributions when the applicability conditions are satisfied.

The meaning of these contributions depends on the chosen initial state, decomposition, observable, neutralization convention, and functional scope. Numerical attribution alone does not establish semantic comparability.

## Case studies

The associated manuscript and implementation materials address the following configurations:

1. **QAOA–MaxCut:** cycle graph C6 with depth `p = 2`.
2. **TwoLocal–H₂:** four-qubit Jordan–Wigner representation with a two-electron-sector restriction.
3. **SKW quantum walk:** hypercube search with oracle, coin, and shift blocks.
4. **QPE–Shor:** quantum phase estimation associated with modular period finding.
5. **Graph partitioning / minimum bisection:** fixed Hamming-weight sector and XY mixer.

The SKW materials distinguish a modified-oracle comparison based on full evolution from an auxiliary fixed-state comparison. These are different experimental questions and should not be interpreted interchangeably.

## Requirements and installation

Use a compatible Python environment. From this directory, install the declared dependencies:

```bash
python -m pip install -r requirements_qsmef.txt
```

The dependency file is the authoritative source for package version constraints.

## Running the implementation

From the `implementacion/` directory:

```bash
python QSMEF_Implementation.py
```

Consult the source code and accompanying output records for the experiments and results generated by this entry point.

## Running regression tests

From the same directory:

```bash
python -m unittest -v test_qsmef_regression.py
```

On Windows, `ejecutar_pruebas.bat` provides an alternative test launcher. See `README_pruebas_QSMEF.txt` for any additional execution notes.

The recorded JSON checks and log files provide reference evidence for reproducibility. A successful regression run establishes consistency with the tested expectations; it does **not** independently validate the scientific interpretation of every result.

## Applicability and interpretation

The framework distinguishes the following reported outcomes:

- `APPLICABLE`
- `NOT APPLICABLE UNDER THE DECLARED SCOPE`
- `SEMANTIC CONTRACT REQUIRED`
- `SPECIFICATION ERROR`

An `APPLICABLE` outcome means that the implemented checks and the researcher-declared criteria are satisfied for the specified configuration. It is **not** a general proof of complete functional or semantic comparability. A negative result under a declared scope must not be generalized to every possible decomposition or circuit configuration.

Semantic contracts can verify formalized properties selected by the researcher, but cannot replace the scientific justification of the observable, the functional decomposition, or the meaning of coalition comparisons.

## Reproducibility limitations

Results are configuration-dependent: changing the initial state, circuit parameters, functional blocks, observable, or neutralization rule can change both applicability and attribution. Numerical values may vary slightly with dependency versions, numerical tolerances, and optimization settings. Regression tests assess computational consistency with recorded references rather than independent experimental confirmation.
