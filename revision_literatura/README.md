# Literature Review Data

This directory contains the data used to document and support the literature review conducted as part of the evaluation and positioning of QSMEF (Quantum Software Engineering Module Evaluation Framework).

The included files provide traceability from the initial set of retrieved studies to the final set of selected studies and the analyses performed on them.

## Data Files

### `data/retrieved_studies.csv`

Contains the bibliographic metadata of the studies retrieved during the literature search.

The records were exported from Zotero and represent the initial study set considered during the selection process.

### `data/excluded_studies.csv`

Contains the bibliographic metadata of the studies excluded during the study selection process.

The records were exported from Zotero and document the studies that were considered but did not form part of the final study set.

### `data/selected_studies_analysis.xlsm`

Contains the final set of 32 selected studies together with the analysis performed on them.

The workbook includes multiple worksheets used to organize, classify, and analyze the selected literature according to the dimensions considered in the study.

These analyses support the characterization of existing approaches in Quantum Software Engineering and the positioning of QSMEF with respect to the identified research landscape.

## Reproducibility

The files in this directory are provided as research artifacts to improve the transparency and reproducibility of the literature review.

The CSV files preserve the bibliographic records exported from Zotero, while the Excel workbook preserves the study selection and analysis used to derive the results reported in the associated research.

No full-text copies of the reviewed publications are included in this repository.
